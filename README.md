# 「轻旅」移动端产品用户体验设计全案 (UX Case Study)

> 专注于年轻人的轻出行决策与智能规划系统。
> 从需求推演、信息架构重构到高保真落地与设计系统规范的全流程 UX Case Study 展示网站。

---

## 🌟 项目背景与核心痛点

针对 18~28 岁年轻群体（在校大学生与职场新锐）在周末短途游中的出行行为推演，发现传统出行产品普遍面临三大体验断点：
1. **商业噪音过载**：主流 OTA 平台充斥大量返利券、特惠机票捆绑与酒店砍价弹窗，决策心智消耗严重；
2. **攻略散乱漫长**：社交内容社区游记以感性打卡自拍为主，缺少时间结构，需翻阅数十篇才能拼凑出完整日程；
3. **现场落地慌乱**：缺乏绝对时间节奏规划与用餐备选预案，现场极易因排队或交通接驳延误导致计划混乱。

---

## 💡 三大核心设计支柱

1. **时钟级结构化时间轴（Clock-level Structured Timeline）**
   - 摒弃模糊的“游玩2小时”，以 08:00、09:00、12:00 等绝对时钟为行动锚点；
   - 配备早餐（咖啡）、景点（定位针）、餐饮（刀叉）动作语义图标；
   - 扁平多日胶囊切换（Day 1 / 2 / 3），将长图文重塑为现场可直接执行的行动清单。

2. **对话即行程：AI 智能行程定制助理（AIGC Travel Companion）**
   - 预设场景化提示词（如“杭州3天学生平价游”），降低输入门槛；
   - 文本秒级转译为可一键保存、可逐项微调的结构化行程卡片；
   - 灵感抽屉态与极简沉浸对话态双态切换，兼顾灵感激发与深度微调。

3. **决策标签前置与双轨内容机制（Decision-First Feed & Dual-Track Publishing）**
   - 首页卡片直接透出“规划时间 2-3天”与“AI智能规划”标签，列表页即可完成时间匹配；
   - 社区分流感性“发布笔记”与理性“发布行程”，沉淀高复用性的结构化路线资产。

## 📱 12 帧界面全景架构

- **核心决策与时间轴 (Core)**：
  - `首页`：决策型双列瀑布流
  - `卡片详情页`：时钟时间轴与避坑贴士
  - `初始页`：天际机翼与轻旅行品牌主张
- **AI 智能规划 (AI Companion)**：
  - `AI 规划助手`：灵感抽屉与引导态
  - `AI 极简沉浸态`：纯粹对话与多轮微调空间
- **城市探索与搜索 (Explore)**：
  - `地点详细页`：轻量地图底图与城市全景
  - `地点详细页-1`：抽屉拉起后的深度攻略聚合
  - `搜索页`：意图检索漏斗与高性价比多维筛选
- **发布与辅助闭环 (Auxiliary)**：
  - `发布中心`：笔记与行程双轨分流
  - `个人中心`：行程资产管理库
  - `消息中心`：轻量互动与旅行搭子即时交流
  - `登录注册页`：自然风景之上的纯净浮层认证

## 🛠️ 工程标准与技术栈

- **纯原生三件套（Zero-Dependency Vanilla Web）**：HTML5 + CSS3 + Vanilla JavaScript，无构建工具负担，开箱即用。
- **设计系统（Design Tokens）**：
  - 核心主色：青空蓝 (`#1B93C4`) / 湖水蓝 (`#22A8D0`) / 深空黑 (`#0F172A`)
  - 模块化流体排版规范与等宽字体（`ui-monospace`）标定；
  - 多层微漫反射环境光投影系统与 1px 半透明发丝级描边。
- **无障碍访问标准（Web Accessibility）**：
  - 全站色彩对比度严格通过 **WCAG AA / AAA** 标准（最高对比度 16.2 : 1）；
  - 全键盘操作与 `:focus-visible` 焦点指示；
  - 尊重操作系统的 `prefers-reduced-motion` 动效减弱偏好。
- **全屏沉浸灯箱查看器（High-Fidelity Lightbox）**：
  - 支持键盘 `ESC` 退出、`←` / `→` 左右方向键无缝翻页。

## 🚀 本地运行指南

无需安装任何第三方依赖（npm install），使用内置 Node.js 脚本即可启动：

```bash
node server.js
```

启动后在浏览器中访问：`http://localhost:3000`（若端口占用会自动顺延至 `3001`）。

或者直接在任何现代浏览器中双击打开 `index.html` 即可完整浏览全部交互与灯箱效果。
